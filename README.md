## ✨ Key Features

- **Cyberpunk Neon Design System**: Custom neon color palette (#00f0ff, #ff0077, #ffd60a, #00f59b) with sleek glassmorphism panels and glowing borders.
- **Ambient Canvas Particles**: High-performance, lightweight HTML5 2D canvas particle simulation running smoothly across desktop and mobile devices.
- **Reading Progress Indicator**: Top fixed glowing progress bar tracking viewport scroll position.
- **Interactive Awards Accordion**: Collapsible award listings showing summary badges by default and expanding full descriptions and achievements on click.
- **Tabbed Verbatim Testimonials**: Interactive tab switcher toggling between River Valley High School and Bukit Panjang Government High School official school testimonials.
- **Responsive Mobile Navigation**: Custom animated hamburger toggle menu with smooth touch navigation for mobile and tablet screens.
- **Verified Credentials Integration**: Direct modal and drive deep-links to certified academic result transcripts and co-curricular documentation.

---

## 🛠️ Tech Stack

- **Markup & Layout**: Semantic HTML5 with accessibility and Open Graph metadata
- **Styling**: Modern CSS3 (CSS Custom Properties, Flexbox, CSS Grid, Glassmorphic blurs, Keyframe animations)
- **Scripting**: Vanilla JavaScript (ES6+, Intersection Observers, Canvas Animation API, DOM event handling)
- **Typography**: Google Fonts (*Orbitron*, *Chakra Petch*, *Nunito Sans*, *Share Tech Mono*)
- **Icons**: Bootstrap Icons (v1.11.1)

## 🚀 Local Development

To run the site locally:

1. Clone the repository:
   `ash
   git clone https://github.com/limjunchuan567/portfolio.git
   cd portfolio
   `
2. Open index.html directly in any modern browser, or launch a local web server:
   `ash
   # Using Python 3
   python -m http.server 8000
   `
3. Visit http://localhost:8000 in your browser.
